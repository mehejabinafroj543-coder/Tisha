NORMALIZATION

Min–max raster normalization

Each raster value is transformed independently into the selected 0–1 range.

No image
Xnorm = (X − Xmin) / (Xmax − Xmin)
Example: if X = 100, Xmin = 50 and Xmax = 200, then Xnorm = (100 − 50) / (200 − 50) = 0.3333. The result is always constrained to 0–1 when the standard output range is selected.

FORMULA REFERENCE

Standard min–max normalization

Xnorm = (X − Xmin) / (Xmax − Xmin)

X = original raster value · Xmin = minimum raster value · Xmax = maximum raster value · Xnorm = normalized value. With output range 0–1, the minimum becomes 0 and the maximum becomes 1.
